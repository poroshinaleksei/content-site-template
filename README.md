# Website template

AI first starter template for small informational websites.

The scaffold is built with Next.js App Router, React, TypeScript, Tailwind CSS,
shadcn/ui style primitives, local typed MDX content, config driven pages and reusable
sections.

## Quick start

```bash
corepack enable
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Main commands

- `pnpm dev`: run the local development server.
- `pnpm build`: create a production build.
- `pnpm start`: run the production server after build.
- `pnpm lint`: run ESLint.
- `pnpm typecheck`: run TypeScript checks.
- `pnpm format`: check formatting.
- `pnpm check`: run lint, typecheck and build.
- `pnpm new:article "Article title"`: create a draft MDX article.
- `pnpm setup`: initialize config and `brief.md` for a new client project.

## Routes

- `/`: home page from `config/pages/home.ts`.
- `/about`: about page from `config/pages/about.ts`.
- `/articles`: article list from `content/articles/*.mdx`.
- `/articles/[slug]`: article detail page.
- `/contact`: contact page with structured links and disabled form delivery.
- `/sitemap.xml`: generated sitemap.
- `/robots.txt`: generated robots file.

## Customization surfaces

- `brief.md`: generated by `pnpm setup`, used as the primary client brief.
- `config/site.ts`: site name, owner, URL, locale and default SEO.
- `config/navigation.ts`: header and footer navigation.
- `config/theme.ts`: theme tokens and typography notes.
- `config/links.ts`: contact destinations, social profiles and external links.
- `config/features.ts`: optional feature selection.
- `config/pages/*.ts`: page composition and section content.
- `content/articles/*.mdx`: local article content.
- `components/sections/`: reusable section implementations.

Keep client specific data in config and content first. Edit components when the requested
layout or behavior cannot be expressed through the existing section contracts.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui compatible local primitives
- `gray-matter` and `zod` for typed MDX frontmatter
- `next-mdx-remote` for MDX rendering
- `@next/third-parties/google` for optional GA4
