This starter uses local MDX as the default content mode. Each article has frontmatter
that is validated before it reaches a page.

## What to edit first

Start with the files in `config/` for site structure and `content/articles/` for writing.
The route components read from the typed loader, so article pages do not parse files
directly.

## Why this matters

Keeping content data behind one loader makes future CMS work easier. A later Decap or
headless CMS integration can target the same article contract without changing every route.
